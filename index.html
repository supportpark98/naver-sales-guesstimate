📊 네이버 판매량 분석 베타 0.1.0-beta

네이버 브랜드스토어 상품의 구매자 수 배지를 읽어 일간·주간 판매량과 추정매출을 보여주는 도구예요.

1. 설치하기 (처음 한 번만)

  1. 크롬에서 Ctrl + Shift + B를 눌러 즐겨찾기바를 켜세요. 이미 보이면 넘어가세요.
  2. 아래 초록색 버튼을 마우스로 끌어서 즐겨찾기바에 놓으세요. 클릭이 아니라 끌어다 놓기예요.
📊 판매량 분석 📊 판매량 분석 (단독)

· 판매량 분석: 기본 버전이에요. 누를 때마다 최신 코드를 불러와서, 업데이트되면 자동으로 반영돼요.
· 판매량 분석 (단독): 기본 버전이 반응이 없을 때 쓰세요. 코드가 버튼 안에 다 들어 있어서 어떤 환경에서든 동작하지만, 업데이트되면 다시 설치해야 해요.

📊 아이콘으로 설치하기 (선택)

끌어다 놓으면 크롬이 지구본 아이콘을 붙여요. 📊 아이콘으로 쓰고 싶으면 아래처럼 설치하세요.

  1. 이 페이지에서 주소창 오른쪽 ☆(별표)를 눌러 즐겨찾기바에 추가하세요. 📊 아이콘으로 저장돼요.
  2. 아래 코드 복사 버튼을 누르세요.
  3. 방금 만든 즐겨찾기를 우클릭 → 수정을 누르고, 이름은 판매량 분석, URL은 지우고 Ctrl+V로 붙여넣은 뒤 저장하세요.

2. 사용하기

  1. 네이버 브랜드스토어 상품 페이지를 엽니다. 예: brand.naver.com/○○○/products/123…
  2. 즐겨찾기바의 📊 판매량 분석을 누르면 화면 오른쪽 위에 분석 창이 떠요.
  3. 분석할 상품을 한 줄에 하나씩 넣습니다.
    • 숫자만 넣으면 → 지금 열려 있는 스토어의 상품으로 조회해요.
    • 다른 브랜드스토어 상품은 → 상품 페이지 주소 전체를 넣으세요.
    • ＋ 지금 보는 상품 추가를 누르면 현재 상품이 목록에 들어가요.
  4. 분석 시작 ▶을 누르면 상품마다 몇 초씩 걸려서 결과가 표로 나와요.
  5. 📋 엑셀용 복사를 누른 뒤 엑셀이나 구글시트에 붙여넣거나, 💾 CSV 다운로드로 저장하세요.

넣어둔 상품 목록은 기억돼서, 다음에 열면 그대로 있어요. 버튼을 한 번 더 누르면 창이 닫혀요.

⚠️ 알아둘 점

  1. 숫자는 구매자 수(명)라서 실제 판매 수량이나 매출보다 작게 나와요. 한 사람이 여러 개를 사거나 비싼 옵션을 사는 경우가 빠지거든요.
  2. 대표가격은 기본 옵션의 즉시할인가예요. 쿠폰이나 카드 혜택이 반영된 최대할인가는 아니에요.
  3. 지금은 브랜드스토어(brand.naver.com) 상품만 지원해요. 일반 스마트스토어는 다음 버전에서 지원할 예정이에요.
  4. 짧은 시간에 너무 많이 조회하면 네이버가 막을 수 있어요. 한 번에 수십 개 이내로 쓰는 걸 추천해요.
  5. 네이버 화면 구조가 바뀌면 동작이 멈출 수 있어요. 베타 버전이라 결과는 참고용으로 써주세요.
